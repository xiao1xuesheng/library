# ELibrary 测试用例文档

## 测试概览

本项目使用 **JUnit 5** + **Mockito** 进行单元测试，采用 Mock 方式隔离外部依赖，对 Service 层、公共组件、工具类进行全面测试。

### 测试技术栈

| 组件 | 版本/说明 |
|------|-----------|
| JUnit 5 | 单元测试框架 |
| Mockito | Mock 框架，配合 `@ExtendWith(MockitoExtension.class)` |
| Spring Boot Test | 集成测试支持 |
| MockMultipartFile | Spring Mock 文件上传测试 |

### 测试文件清单

| 测试类 | 被测模块 | 测试用例数 | 覆盖场景 |
|--------|----------|-----------|----------|
| `UserServiceTest` | 用户服务 | 17 | 注册、登录、用户管理、状态变更 |
| `BookServiceTest` | 书籍服务 | 12 | 书籍列表、详情、创建、更新、状态管理 |
| `BorrowServiceTest` | 借阅服务 | 13 | 借阅、归还、续借、借阅记录查询 |
| `ReviewServiceTest` | 评论服务 | 14 | 评论创建、查询、更新、删除、管理员删除 |
| `NoteServiceTest` | 备注服务 | 11 | 备注创建、查询、更新、删除 |
| `ReadingServiceTest` | 阅读服务 | 7 | 阅读进度保存、查询、历史记录 |
| `PaymentServiceTest` | 支付服务 | 14 | 订单创建、支付回调、VIP激活、账单上传 |
| `AdminServiceTest` | 管理员服务 | 11 | 管理员创建、登录、角色管理、禁用 |
| `JwtUtilTest` | JWT工具类 | - | Token生成、解析、验证 |
| `BusinessExceptionTest` | 业务异常 | - | 异常构造、错误码 |
| `GlobalExceptionHandlerTest` | 全局异常处理 | - | 异常拦截、统一响应 |
| `ApiResponseTest` | 统一响应 | - | 成功/失败响应构造 |

./mvnw test jacoco:report
