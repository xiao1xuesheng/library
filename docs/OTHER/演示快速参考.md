## 演示流程 & API

### 1. 登录
```bash
curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"demo_user","password":"123456"}'
```
> 复制返回的 `token`

### 2. 浏览书籍
```bash
# 所有书籍
http://localhost:8080/api/books?page=1&size=20

# 搜索
http://localhost:8080/api/books?keyword=Java

# 分类
http://localhost:8080/api/books?category=编程语言
```

### 3. 书籍详情
```bash
http://localhost:8080/api/books/1
```

### 4. 借阅书籍
```bash
curl -X POST http://localhost:8080/api/borrow \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <TOKEN>" \
  -d '{"bookId":2,"requestId":"demo-001"}'
```

### 5. 查看我的借阅
```bash
http://localhost:8080/api/my/borrows
```
Header: `Authorization: Bearer <TOKEN>`

### 6. 归还书籍
```bash
curl -X POST http://localhost:8080/api/borrow/1/return \
  -H "Authorization: Bearer <TOKEN>"
```
