## 五、完整演示脚本（一键执行）

如果需要快速演示，可以复制以下脚本到终端执行：

```bash
#!/bin/bash

# ELibrary 演示脚本
BASE_URL="http://localhost:8080"

echo "========================================="
echo "  ELibrary 演示脚本"
echo "========================================="

# 1. 登录
echo ""
echo "【步骤 1】用户登录..."
LOGIN_RESPONSE=$(curl -s -X POST $BASE_URL/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username": "demo_user", "password": "123456"}')

echo "登录响应: $LOGIN_RESPONSE"

# 提取 Token（需要安装 jq）
TOKEN=$(echo $LOGIN_RESPONSE | jq -r '.data.token')
echo "获取到 Token: ${TOKEN:0:20}..."
echo ""

# 2. 浏览书籍
echo "【步骤 2】浏览书籍列表..."
curl -s -X GET "$BASE_URL/api/books?page=1&size=20" | jq .
echo ""

# 3. 查看书籍详情
echo "【步骤 3】查看《Java核心技术 卷I》详情..."
curl -s -X GET $BASE_URL/api/books/1 | jq .
echo ""

# 4. 借阅书籍
echo "【步骤 4】借阅《Spring实战 第6版》..."
BORROW_RESPONSE=$(curl -s -X POST $BASE_URL/api/borrow \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"bookId": 2, "requestId": "demo-req-001"}')

echo "借阅响应: $BORROW_RESPONSE"
BORROW_ID=$(echo $BORROW_RESPONSE | jq -r '.data.id')
echo "借阅记录ID: $BORROW_ID"
echo ""

# 5. 查看我的借阅
echo "【步骤 5】查看我的借阅记录..."
curl -s -X GET "$BASE_URL/api/my/borrows" \
  -H "Authorization: Bearer $TOKEN" | jq .
echo ""

# 6. 归还书籍
echo "【步骤 6】归还借阅记录ID为 1 的书籍..."
curl -s -X POST $BASE_URL/api/borrow/1/return \
  -H "Authorization: Bearer $TOKEN" | jq .
echo ""

echo "========================================="
echo "  演示完成！"
echo "========================================="
```

保存为 `scripts/demo.sh` 并执行：
```bash
chmod +x scripts/demo.sh
./scripts/demo.sh
```

## 八、常见问题

### Q1: 借阅失败，提示 "Balance insufficient"
**A**: 用户余额不足。可以通过 H2 Console 增加用户余额：
```sql
UPDATE t_account SET balance = 500.00 WHERE user_id = 1;
UPDATE t_user SET balance = 500.00 WHERE id = 1;
```

### Q2: 借阅失败，提示 "Already borrowed this book"
**A**: 该用户已经借阅了这本书且未归还。需要先归还或查看其他书籍。

### Q3: 借阅失败，提示 "Borrow limit exceeded"
**A**: 普通用户最多借阅 3 本，VIP 用户最多借阅 10 本。需要归还部分书籍后再借阅。

### Q4: Token 过期怎么办？
**A**: 重新登录获取新 Token。Token 有效期为 24 小时。

## 九、演示注意事项

1. **提前准备**：演示前确保应用已启动且数据已初始化
2. **Token 管理**：登录后的 Token 要妥善保存，后续请求都需要使用
3. **演示顺序**：建议按照 浏览 → 详情 → 借阅 → 查看 → 归还 的顺序进行
4. **数据重置**：如需重新演示，重启应用即可（H2 内存数据会清空并重新初始化）
5. **网络环境**：确保演示环境网络稳定，localhost 可正常访问
